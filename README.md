# Pedestrian Traffic Light Detection with Tiny YOLOv4 Object Detector

## OAK-D
- OpenCV DepthAI device.
- Stereo camera for depth.
- Built with Intel VPU (Visual Processing Unit) inside.

## Functions
- Pedestrian traffic light detection (Red/Green).

## Object descriptor
- Custom object descriptor trained using the Tiny YOLOv4 model.
